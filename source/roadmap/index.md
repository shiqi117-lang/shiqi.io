## 为什么还没放弃性能优化这条线

调研显示 AI Infra 岗位的硬门槛已经变成 CUDA，而 3 个月内同时吃 C++ 性能主线 + CUDA
必然两头不扎实。所以这里是明确的取舍：**先把通用的性能工程能力做扎实**。

好消息是，推理优化里 CPU 侧的那部分（算子融合、量化、KV cache 内存管理、访存优化）
本质上就是你路线里阶段 02/03/05/06 的内容。把通用能力打牢，后面真要往 AI Infra 转，
只需要补 CUDA 和模型结构两块，迁移成本比从零开始低得多。

项目二特意留了一个 **INT8 量化 matmul（纯 CPU / SIMD）** 的选项——不碰 GPU，
但能让简历沾上「推理优化」的叙事，成本只有一两周。

## 怎么判断该不该跳过

拿不准时问自己三个问题：

1. 过去半年我在面经里见过它三次以上吗？
2. 面试官会不会追问到实现细节？如果会，我能现场写出来吗？
3. 我能不能在两分钟内把它讲清楚，并说出一个使用场景？

三个都答不上来 → 标「了解」，写进 skip 清单，然后跳过。三个都能答 → 才值得投时间到「精通」。
